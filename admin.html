Panel de Administración

Vista de solo lectura (salvo el estado de las solicitudes de servicio) sobre los datos reales de este prototipo: usuarios, servicios solicitados, reservas, formación, consultas del Chat y pagos simulados. Ningún número que se muestra aquí está inventado — si no hay datos, el panel simplemente lo indica.

Resumen general

Sobre este panel

Este es un prototipo académico sin backend ni base de datos: todo lo que ves aquí vive únicamente en el localStorage de este navegador. Los registros marcados con la etiqueta DEMO fueron creados automáticamente para poder presentar el panel y pueden eliminarse con el botón de arriba; el resto son datos reales generados por el uso del prototipo (registro, reservas, inscripciones, chat, pagos simulados) en este mismo navegador.

Usuarios registrados

Nombre, correo, fecha de registro, rol y estado de cada cuenta creada en este navegador. Las contraseñas nunca se muestran: solo se guarda su hash con salt (ver sección 1.1 de js/main.js), nunca en texto plano.

Solicitudes de servicios

Cada envío del formulario de Contacto se registra aquí como una solicitud de servicio. El estado puede actualizarse desde este panel (Pendiente, Confirmado, Atendido o Cancelado); el cambio se guarda de inmediato en este navegador.

Reservas

Todas las asesorías agendadas por todos los usuarios de este navegador, con el mismo estado que ya ven en "Mis reservas" (Confirmada / Cancelada).

Formación / Inscripciones

Inscripciones reales a cursos, con su fecha y su estado (En progreso / Completado), igual que en "Mis cursos".

Consultas

Resumen de las conversaciones reales del Chat de demostración (Mensajes): usuario, asesor de demostración, cantidad de mensajes y fecha del último. El Chat es un prototipo de mensajería sin conexión en tiempo real y sin asesores reales conectados; aquí solo se muestra lo que ya quedó guardado, nunca una conversación inventada.

Pagos simulados

Únicamente simulaciones académicas expresadas en Unidades Demostrativas (UD): esta plataforma no procesa cobros reales ni guarda datos de tarjetas.
